Responsive Typography

Font sizes change with screen width

This paragraph uses a small font on mobile, a medium font on tablets and a larger font on desktop screens. Resize the browser window to see the text change at each breakpoint.

Why it matters

Text that is comfortable on a large monitor can be too big on a phone, and text sized for a phone looks tiny on a desktop. Media queries let us choose the best size for each device.

Breakpoints used

Mobile: under 768px. Tablet: 768px - 991px. Desktop: 992px and up.
